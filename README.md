# Friendlot 3D V2

スマホ向け3Dタイクーンの試作版です。Three.jsをCDNから読み込みます。

## 公開
Cloudflare Pagesでこのフォルダの中身を静的サイトとして公開してください。ビルドコマンドは空欄、出力ディレクトリは `/`。

## 操作
- スマホ：左下のスティックで移動。レーン上のキャラに近づき右下の購入ボタン。
- PC：WASD / 矢印キー。
- 「収益を回収」で所持キャラの収益をCashに加算。
- リバースは初回$1,500、2回目$3,000。Cashの75%と未回収収益の半分を失い、所持キャラは一部残る。最大3階。
- ベースは8個、中央にレーン1本。

## キャラ追加
`character.json` の `characters` に追加。必須の目安:
`id`, `name`, `color`, `accent`, `price`, `income`, `rarity`

## 注意
これはプレイ確認用プロトタイプです。セーブ、マルチプレイ、サーバー側の購入検証、アカウント認証は未実装です。公開前にサーバー側検証を追加してください。現在の購入・収益はブラウザ内だけで計算されます。
