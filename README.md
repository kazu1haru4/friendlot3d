# Friendlot 3D V4

中央の赤いキャラレーンと、入口・壁・表示台を持つ8個のベースを備えた3Dプロトタイプです。

## 公開
GitHub Pagesで `main` ブランチの `/(root)` を選択してください。

## 操作
- スマホ：左下スティックで移動し、レーンのキャラの近くで購入ボタンを押します。
- PC：WASDまたは矢印キーで移動します。
- 購入したキャラは自分のベースまで移動し、到着後に収益を生みます。
- 収益を回収ボタンでCashに加算します。
- リバースで最大3階建てになります。

## キャラ追加
`character.json` の `characters` 配列にキャラ情報を追加します。`id`, `name`, `color`, `accent`, `price`, `income`, `rarity` を設定してください。
